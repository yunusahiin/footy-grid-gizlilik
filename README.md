# Footy Grid — gizlilik politikası

Bu depo yalnızca **Footy Grid** mobil oyununun gizlilik politikasını barındırır.
Google Play, gizlilik politikasının herkese açık bir adreste durmasını şart koşuyor;
bu depo GitHub Pages ile o adresi sağlıyor. Oyunun kaynak kodu burada değildir.

Yayındaki adresler:

- https://yunusahiin.github.io/footy-grid-gizlilik/
- https://yunusahiin.github.io/footy-grid-gizlilik/gizlilik ← Play Console'a girilen URL

`gizlilik.md` politikanın **tek kopyasıdır**. Uygulama veri toplamaya başlarsa
(örneğin reklam eklenirse) önce burası güncellenir, sonra Play Console'daki
Veri Güvenliği formu.
